## 2. 评测结论(最重要的部分)

我们对"委员会到底行不行"做了系统性评测。**每一条结论都标注了证据强度**——这套项目的评测纪律就是不把弱证据包装成结论。

### 2.1 委员会曾有系统性缺陷(已校准)
- **发现**:回放 60 条决策,**96.7% 说买、0% 卖**,58 条买入里 45 条置信度都是 0.85 → 决策几乎不带信息量,真正在做决定的是闸门。
- **校准**(prompt 改造):候选是预筛过的→"走势强"是基线不是买入理由;hold 合法;置信度用满 0–1 区间(给锚点、明写"不要习惯性给 0.85");主席须逐条回应空头。
- **A/B 结果**(同 12 交易日、各 60 条):买入 96.7%→**63.3%**;置信度 stdev 0.05→**0.126**;最常见值占比 78%→47%;四条诊断 flag 只剩一条。**结构性区分度确实改善(直接可测)。**

### 2.2 委员会确实读市场环境(跨区间验证)
- 同结构在**下跌窗口**(SPY −12%)重放:买入率 **63.3%→20.0%**,置信度最低给到 0.40。→ 不是"总是买"的固定比例,宏观 regime 起了真实作用。**校准未过拟合到某段行情**(熊市窗口 flat_confidence/confidence_floor 都没触发)。

### 2.3 卖出行为:先被误判、跨区间纠正
- 上涨窗口里 14 条卖出 5 日命中率 0%、卖完平均涨 8% → 一度以为"卖出反预测"。
- **下跌窗口纠正**:卖出率 11.7%→42.5%,5 日卖出比持有少亏 1.2 个百分点(−1.98% vs −3.19%),命中率 43%。→ **上涨窗口的"卖出反预测"是行情产物,不是真缺陷。** 卖出逻辑既没被证伪也没被证实,不动它。

### 2.4 置信度→收益:**测了,不显著(2026-08 升级为够样本的结论)**
- 早期是"样本不足,看不出"。2026-08 用三区间(牛/熊/震荡)干净重跑(72 决策 / 24 天 / **fail-safe 0%**),买入 **39 条 / 22 个决策日首次跨过显著性门槛**:1 日 r=0.158(t=0.715<临界 2.086)、5 日 r=0.055,**均不显著**。
- **口径升级**:从"样本不足无法判断" → "**测了,现有证据里置信度不预测收益**"。收益本身跨区间池化(5 日买入 −2.0% 跑输持有 +0.6%),非纯 alpha。
- **结论口径**:结构性指标(分布、区分度)的改善是**直接可测的真事**;收益的改善是**未经检验的观察**;两者不能混为一谈。

### 2.5 M8 学习闭环:**机制通电成功,但委员会对自己的复盘几乎无响应**(2026-08)
- **通电(机制)✅**:`scripts/replay_loop.py` 在隔离库里按历史日期推进**完整** `run_trade_cycle`(含撮合/平仓/复盘)。实测(2025-03~04 熊+反弹,25 天,fail-safe 0%):**2 笔平仓往返 → 写出 2 条 trade_review 进记忆**。那条"建好但没通电"的学习线确实产电了。
- **学到没有?(行为)——几乎没有**:`scripts/learning_ab.py` 做 difference-in-differences(WITH vs WITHOUT memory,有复盘的 AMD/JPM vs 无复盘的 AAPL/MSFT)。结果 **DiD = −0.008 ≈ 0**:有记忆会让委员会略谨慎(通用效应),但"我们在 JPM 亏了 11.8%"这条**具体复盘几乎不额外改变**对该票的行为。样本极小(机制探针非结论),但方向清楚。
- **对 M9 的直接改写**:历史复盘**已经喂进** memory_context(2000+ 字),瓶颈不是"喂",是**委员会没有有效权衡它** —— 是 prompt/框定问题,不是数据管道问题。
- **M9 两次 prompt 干预都被 learning_ab(Wilson CI)拦下**:①强化 memory 段 → 区间重叠、无可测效应;②把该票上次结果**显眼摆 prompt 顶部** → **适得其反**,treatment WITH 0.81 [0.65,0.91] vs WITHOUT 0.53 [0.36,0.69],显眼提醒亏损反让委员会**买得更多**(疑似报复/抄底)。**已否决,绝不接线上。** 这是"测量拦下面上显然正确、上线会造成危害的改动"的又一实例——真要规避重复亏损需**结构化约束**(bear 强制质询该票亏损 / 量化盈亏字段),不是情绪化叙事。

### 2.6 证据强度总声明
现有评测多来自**单一或少数行情区间**,基本面回放还带**未来函数**(拿今天的财报判过去的决策),universe 有**幸存者偏差**。因此所有"agent 决策好/坏"的判断都是**弱证据**。跨区间验证已作为方法论固化,但要下强结论仍需更多独立样本(见 ROADMAP M8)。

## 3. 评测过程中我们修正的自身错误(诚实记录)

评测工具本身也会骗人。以下是我们**发现并修掉的、自己造的**测量缺陷——它们比功能 bug 更隐蔽:

1. **只数条数、不数天数**:置信度显著性门控最初按行数(n≥20),但 36 条同天决策≈1 个观测(截面相关),r=0.112 被当成了结论。→ 改为须覆盖 ≥5 个不同决策日。
2. **显著性仍按行数算 t**:即便加了天数门,t 统计量还用行数,r=0.257 看着"勉强显著"实为 t=0.84 完全不显著。→ 改为 `df=决策天数−2` 的保守 t 检验 + 主导置信度 caveat。
3. **命中率裸奔**:sell 5 日命中率 0/14 看着像铁证,实则只落在 3 只标的/8 天。→ `n` 永远伴随 `distinct_symbols/days` 一起显示。
4. **分母缺陷**:`no_sells` 用全部决策做分母,但卖出只可能出现在持仓决策里。→ 决策落 `held` 字段,分母改用持仓决策;无持仓时报 `sell_untestable` 而非误判"不肯卖"。
5. **inf 序列化 500**:相关系数恰为 ±1.0 时 t=inf,JSON 序列化失败会 500。→ 对外降级为 null,显著性结论不变。

**教训**:样本量门控要按**独立观测数**设,不是按行数;单一行情区间得出的行为结论几乎必然是区间产物。
